# Пиксельград

Онлайн-экономика в браузере: вымышленный город с панельками, деревня, дачи, промзона, порт.
Работай → копи → покупай землю → строй цепочки → открывай точки в городе и офисы в бизнес-центрах, обставляй квартиру и зови друзей.

- Клиент: статичный сайт (Three.js, пиксельный low-poly), `index.html` + `js/`.
- Сервер: Supabase (Postgres + Auth + Realtime). Вся экономика — в RPC-функциях `sql/001_schema.sql`, производство считается лениво по времени (работает и офлайн).
- Данные мира генерируются из `js/config.js` и `js/layout.js`: `node tools/gen_sql.mjs > sql/002_data.sql`.

## Запуск
1. Применить `sql/001_schema.sql`, затем `sql/002_data.sql` в Supabase.
2. В Supabase: Auth → Email → выключить «Confirm email» (почтовый сервер пока заглушка).
3. Вписать publishable/anon-ключ в `js/supabase-config.js`.
4. Открыть через любой статический хостинг (GitHub Pages).
